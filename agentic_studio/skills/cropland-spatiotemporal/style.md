# 文风指南 —— 耕地时空演变简报

面向自然资源主管部门的**政务数据简报体**。核心：用数据说话，趋势判断有据，语气客观克制。

## 语气与体例
- **务实、客观、克制**：以数据事实为骨架，趋势判断紧贴数据；避免空泛抒情与过度修辞（不写“春风化雨”式套话）。
- **数据锚定**：每个判断尽量挂在具体数值上；先陈述数据，再下趋势结论（“……，总体呈增加态势”）。
- **政策语境适度**：可在原因/成效类小节点到政策背景（占补平衡、土地整治、生态退耕、耕地保护），但不脱离数据空谈。

## 用词与格式
- 单位统一 **万亩**，数值保留 **2 位小数**；占比用 **%**；破碎度用 **个/万亩**。
- 时间锚点**以证据覆盖为准**：证据含 2019 年（“三调”基年）时，用“‘三调’以来”“‘三调’至今”表述；
  证据从更晚年份起（如限定 2020—2023）时，**以证据首个年份为“期初”**，不得引入证据之外的年份或基年标签。
- 规范术语：耕地 / 二级类（水田、水浇地、旱地）/ 净增加 / 净减少 / 流入 / 流出 / 稳定耕地 / 不稳定耕地 / 破碎度 / 坡度等级。
- 市（州）一律写作“市（州）”；四川省 21 个市（州）。

## 句式范式（示例）
- 总体：“‘三调’时期该地区耕地总面积为 X 万亩，此后历年分别为 …，总体上呈 增加/减少 态势。”
- 增减分解：“其中 A 减少 X 万亩，B 增加 Y 万亩。”
- 分区：“呈净增加的市（州）包括 …；呈净减少的包括 …，其中 … 超过 X 万亩。”
- 成效：“通过 …（政策/工程），该地区 … 得到 …，为 … 奠定基础。”

## 图表
- 图表由系统按大纲声明**自动生成并插在节末**（数据直出）；行文用「下图」「下表」自然衔接即可，
  **不要**在正文里复述图表的全部数据，只点关键值与结论；不要自行编表或描述不存在的图。

## 硬约束（grounded）
- **只用证据中的数值**：所有数字必须来自提供的证据（DB 指标），**严禁杜撰或外推未给出的数值**。
- 证据未覆盖的判断（如缺人口数据时的人均耕地）：**明确标注数据缺口**，不要编造。
- 每处载荷性数值表述后附证据引用标记 `[证据id]`（装配时统一重编号）。
